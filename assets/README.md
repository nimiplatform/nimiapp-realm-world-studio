## Generation prompt

Use case: logo-brand. Asset type: production desktop application icon for Realm World Studio, a creator workspace to organize and build fictional worlds. Create ONE standalone square PNG icon, exactly 1024 x 1024 pixels, on a truly transparent background. A distinct compact world-building emblem: an elegant small globe assembled from three broad layered landforms, with a clean horizon and one short orbit-like curve; a calm sculptural silhouette, not a generic Earth stock icon. Palette grounded in the existing app colors teal #2f8f83 and indigo #6366f1, with a pale turquoise highlight. Clean vector-like raster design, broad simple shapes, crisp anti-aliased edges, restrained smooth gradients, no grain and no photographic texture. Centered mark about 78% of canvas with even clear margins. Clear at 32 px on light and dark interfaces. No text, no letters, no humans, no chess pieces, no sci-fi background, no app mockup, no opaque square background, no heavy shadow. Deliver only the icon. Prefer simple colors and efficient PNG encoding suitable for an icon asset below 512 KiB.
